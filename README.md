# 🧠 Cervical Cancer Prediction using Machine Learning

## 📌 Overview

This project presents a comparative study of Machine Learning models for cervical cancer prediction using patient clinical data.

The objective is to evaluate different classification algorithms and compare their performance using standard evaluation metrics.

---

## 🎯 Objectives

- Data preprocessing
- Missing value treatment
- Exploratory Data Analysis (EDA)
- Feature selection
- Model training
- Model evaluation
- Performance comparison

---

## 📂 Dataset

**Cervical Cancer Risk Factors Dataset**

The dataset contains information from **858 patients**, including:

- Demographic information
- Behavioral characteristics
- Medical history
- Risk factors
- Schiller test results

---

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

---

## 📊 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC AUC
